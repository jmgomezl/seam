# Visual first-use hierarchy

Guided replay now shows inputs and one primary run action before execution, rather than empty result panels. Actual recorded counts become the largest result elements after execution; raw IDs and event metadata remain available in native keyboard-accessible disclosures. Counts are derived from the returned ledgers, never optimistic placeholders.

The stepper marks the active step for assistive technology. The local-handler handoff appears after the overlap step instead of competing with the comparison action. Advanced AI tools are grouped separately. Narrow-screen styles keep counts side-by-side when space permits and stack at very small widths; controls preserve visible focus and touch targets.

Validation: real replay and DOM-double navigation tests, unit tests for error/escaping/count fidelity, TypeScript, build. Native browser capability was not available, so visual layout, zoom, screen-reader behavior and real browser interactions remain unverified. No Firebase or execution engine changes.
